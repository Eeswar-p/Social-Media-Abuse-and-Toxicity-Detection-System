⚙️ How It Works

7-Layer Detection Pipeline

XLM-RoBERT — Rule-based heuristic NLP pipeline (not pre-trained deep learning). 250+ keywords, 7 intelligent layers, context-aware with negation handling.

1
Keyword Matching — 250+ toxic keywords scored by category (Threat, Hate, Insult, Obscenity), per-word confidence 0.0–1.0
2
Proximity Combo — Derogatory words near person nouns (you, he, she, person) within ±4 words → amplify Insult score
3
Phrase Matching — 60+ exact toxic phrases ("waste of space", "go die", "drop dead", "i will kill you")
4
Sarcasm Detection — Pattern matching for sarcastic keywords ("yeah right", "obviously", "oh sure")
5
Negation Dampening — "not/never/don't/can't" within 3 words of toxic word → 75% score reduction
6
Context Reducers — Gaming (kill, boss, pvp), Medical (cancer, patient), News (alleged, suspect) → 45% multiplier
7
Safe Word Whitelist — 80+ words (nice, good, love, art, music, python) never flagged regardless of context
✓ "kill the bug" → SAFE (tech context) ✓ "don't be stupid" → SAFE (negated) ⚠ "you waste of space" → 88% TOXIC ⚠ "I will destroy you" → 90% THREAT

🏗️ Architecture

Full-stack async pipeline

FRONTEND (React 19 + Vite)
📱 Text Input — Real-time live inference (debounced 380ms)
📂 File Upload — .txt, .csv, .json auto-detection
🌐 URL Analyzer — Web scraping interface
📊 Charts — Recharts (Area history + Radar categories)
🔴 Live Stream — Simulated chat moderation
⚙️ Sensitivity Control — Threshold slider (0.3–1.0)
BACKEND (FastAPI + Python 3.10+)
⚡ FastAPI — High-performance async REST API
🔄 asyncio.gather — Parallel batch inference (500 texts ~200ms)
📥 Pydantic v2 — Request/response validation
🌐 httpx — Async HTTP client for URL fetching
🧠 XLM-RoBERT — 7-layer heuristic pipeline
💾 Uvicorn — ASGI server with hot-reload
PRODUCTION ENDPOINTS
POST /analyze
{text, threshold} → risk_score, labels, highlights

POST /analyze-bulk
{texts[], threshold} → parallel results

POST /analyze-file
multipart file → parse + analyze

POST /analyze-url
{url} → fetch, strip HTML, score

GET /health
→ Status + available endpoints
